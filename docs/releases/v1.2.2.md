## agent86-core 1.2.3

This release updates the agent inside the app to agent86 1.2.3. It works better with local models,
and threads get the improvements without any setting:

- **Context sized to the model's window.** Long tool results are trimmed to fit, keeping their
  start and end, and older results are sent in short form once a conversation fills half the
  window. On a small window (20k tokens, for example) the agent finishes more tasks in about half
  the time, and compacts far less often. The session keeps every result in full.
- **Compaction that keeps the task.** A long turn can be compacted while it runs, and your message
  stays word for word, so the agent doesn't lose track of what you asked.
- **It knows where commands run.** The agent is told the platform, the shell, and the Python
  command (`python` on Windows), so it no longer tries `python3` or Linux paths on Windows.
- **A nudge when it goes in circles.** When the agent repeats a failing call, gets the same failure
  three times, or reads the same thing three times, it is reminded once to change its approach.
- **Content filters and refusals** from a provider show as the provider stopping, instead of an
  empty answer the agent asks about again.

Sessions, memory, keys, and settings are unchanged and still shared with the agent86 CLI.
