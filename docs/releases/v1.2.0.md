## Markdown viewer

Markdown the agent writes now opens rendered, beside the conversation, instead of only as source.

- **View a document.** A Markdown file on a tool card (`.md`, `.markdown`) has **view**, next to
  **open** and **reveal**. A finished reply has **View as document**. Either opens in a pane beside
  the conversation, rendered as GitHub shows Markdown: headings, task lists, tables, `> [!NOTE]`
  alerts, footnotes, highlighted code, and front matter as a folded table.
- **Rendered or Raw.** Switch between the document and its source; **Contents** lists the headings
  and jumps to one.
- **Follow links.** Web and mail links open in your browser or mail app. A link to another Markdown
  file opens it in the pane, and **←** goes back. A link to any other file, or a reference such as
  `src/app.ts:42`, opens that file with the same rules as **open**.
- **Safe by default.** The viewer reads only files in the thread's workspace (or a worktree its
  sub-agents kept), up to 2 MB. Images are never loaded, as in replies; each shows as a link.
  Raw HTML shows as text, and the rendered document is cleaned once more before it is shown.
- **Your pane.** Drag its left edge to resize it (the width is remembered); **✕** or **Esc** closes
  it. Each thread has its own. It follows the light and dark themes.
